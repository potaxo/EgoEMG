## 快照约定

- 每轮使用独立的日期与主题目录，包含 `README.md` 和 `snapshot_manifest.json`。
- 报告和证据文件从已验证的正式输出中精选，按原始字节保存。manifest 记录源路径与 SHA-256；导出时的 checkout commit 不代表实验执行版本。
- 原始报告中的本机绝对路径和历史验证记录保留用于追溯。GitHub 阅读从快照说明提供的相对链接开始；本地路径不代表仓库中附带了完整运行目录。
- 结果快照可供核对汇总数值。完整的预测级复算、恢复运行与重训练需要本地 `outputs/`、数据及 checkpoint。
- 失败运行、缓存、参数文件、逐窗口数组、完整日志与 Word/PDF 副本不随快照收录。图片只选择帮助解释结果的图表。
- 本次为整理已有结果，没有重新执行实验；各报告中记录的测试与验证属于原实验执行历史。
